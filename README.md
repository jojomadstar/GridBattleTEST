# Pulse Deck Prototype

Browser prototype for a grid-based action card battler.

## Shared project context

Read [PROJECT.md](PROJECT.md) for current design decisions, implementation notes,
tests, pending work, and deployment status. All models maintain this one handoff document.

## Play locally

Open `index.html` in a browser, or serve the folder with a small static server.

## GitHub Pages

This project is a static site. After pushing it to GitHub, enable GitHub Pages from the repository settings and publish from the default branch root folder.
